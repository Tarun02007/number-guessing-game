# 🎯 Number Guessing Game

A clean, interactive command-line game built with Python that challenges players to guess a randomly generated number. 

---

## 🚀 Features
* **Dynamic Feedback:** Real-time hints letting the player know if their guess is too high or too low.
* **Score Tracking:** Keeps track of the total number of attempts it takes to guess correctly.
* **Input Validation:** Error handling to prevent the program from crashing if a user types text instead of a number.

## 🛠️ Tech Stack
* **Language:** Python 3.x
* **Core Modules:** `random` (for number generation)

## 💻 How to Run Locally

1. Make sure you have Python installed on your system.
2. Clone or download this repository.
3. Open your terminal/command prompt inside the project folder.
4. Run the application using the following command:
   ```bash
   python main.py
   ```
